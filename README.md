# Kallista by Ronadisa

موقع تصوير احترافي متجاوب مبني بـ React وVite، مع لوحة إدارة، ألبومات، حجوزات، تقييمات، رفع صور عبر ImgBB، وتخزين آمن في Firebase.

## التشغيل المحلي

```bash
cp .env.example .env.local
npm install
npm run dev
```

## التحقق والبناء

```bash
npm run lint
npm run build
```

يتم نشر فرع `main` تلقائياً على GitHub Pages من خلال `.github/workflows/deploy-pages.yml`، ومسار الإنتاج مضبوط على `/Kallista/`.

## الأمان

- دخول الإدارة يتم فقط عبر Firebase Authentication والتحقق من UID المدير.
- لا توجد كلمة مرور افتراضية أو PIN داخل كود الموقع.
- التقييمات تتطلب حساب عميل وتبقى معلقة حتى موافقة المدير.
- الحجز وتسجيل "ابقَ على تواصل" مفتوحان للزوار بدون حساب، ومحميان بقواعد تحقق صارمة في `firestore.rules` (تحقق من نوع كل حقل وطوله، ومنع انتحال حساب عميل آخر).
- قواعد Firestore الجاهزة موجودة في `firestore.rules` ويجب نشرها من Firebase Console.


## ما الجديد في هذه النسخة (دمج فيلورا + كاليستا)

هذه النسخة تدمج أفضل ما في مشروع فيلورا داخل كاليستا:

| الإضافة | التفاصيل |
| --- | --- |
| **المحافظة والمركز/المدينة** | قائمة الـ27 محافظة مصرية بالعربي والإنجليزي (`src/data/egyptGovernorates.ts`) في استمارة الحجز الكاملة والاستمارة السريعة. القيمة المخزّنة إنجليزية ثابتة حتى لا تتأثر الفلترة والتصدير بتغيير اللغة. |
| **حجز بدون حساب** | لم يعد إنشاء حساب شرطاً لإرسال طلب حجز. تسجيل الدخول اختياري ويربط الطلب ببروفايل العميل فقط. |
| **قسم "ابقَي على تواصل"** | قسم مستقل (`StayInTouchSection`) يجمع الاسم وتاريخ الميلاد والمحافظة والمدينة والتليفون والإيميل من أي زائر حتى لو لم يحجز — وهو مصدر قائمة التهاني. |
| **تنبيهات المناسبات الإسلامية** | رمضان وعيد الفطر وعيد الأضحى ورأس السنة الهجرية، محسوبة من تقويم أم القرى عبر `Intl` (بدون مكتبات إضافية) وتظهر في تبويب العملاء مع رسائل تهنئة جاهزة. |
| **تصدير Excel/CSV** | أزرار تصدير في تبويبي العملاء والحجوزات. الملف بترميز UTF-8 مع BOM حتى تظهر العربية سليمة في Excel. |
| **اتصال سريع** | أزرار اتصال (`tel:`) وواتساب وبريد إلكتروني (`mailto:`) مباشرة من جدول العملاء. |

### ⚠️ مهم بعد التحديث

`firestore.rules` **تغيّر**. لازم تنشره من Firebase Console (Firestore Database ← Rules ← لصق المحتوى ← Publish)،
وإلا سيفشل الحجز وتسجيل "ابقَ على تواصل" برسالة `permission-denied`.
